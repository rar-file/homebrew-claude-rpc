# homebrew-claude-rpc

Homebrew tap for [claude-rpc](https://github.com/rar-file/claude-rpc) — Discord Rich Presence for Claude Code.

```sh
brew install rar-file/claude-rpc/claude-rpc
claude-rpc setup
```

The formula is generated from the published npm tarball by [`scripts/brew-formula.mjs`](https://github.com/rar-file/claude-rpc/blob/main/scripts/brew-formula.mjs) in the main repo and synced here on each release.
